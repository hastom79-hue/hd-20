## OCR로 불명확했던 부분 — 제 판단으로 채운 곳 (필요시 알려주시면 수정)
- p.21 "명칭변경 As-is/To-be" 문구가 스캔 상태로 완전히 판독되지 않아, **"전월 점검결과(고정) + 개선내역 + 조치완료"** 조합으로 해석해 구현했습니다.
- p.22 "5S활동명" 목록이 요청서 내에서도 페이지마다 표기가 갈려 있어(정리·정돈·청소·시각화·자주보전 / 정리·정돈·청소·청결·습관화 등), 표 컬럼에 실제로 인쇄된 **6종(정리·정돈·청소·시각화관리·습관화·자주보전)** 을 기준으로 통일했습니다.
- p.24 HDPS21 등록화면의 정확한 필드명 일부(예: "대개선", "수정면제")는 해상도상 완전히 읽히지 않아, 문맥상 가장 가까운 명칭(대개선위치, 검토유무 성격의 표준화 체크)으로 대체했습니다.
- "표준화" 플래그는 개선건 단위(Y/N)로 관리된다고 보고 `REQUESTS`에 `standardized` 필드로 반영했습니다(요청서 p.19 "5S 상세내역" 표의 "표준화" 컬럼 근거).
