# GMES HDPS 5S 활동관리 Prototype

첨부 화면설계 요청서를 기반으로 구성한 GMES HDPS 5S 웹 UI 프로토타입입니다.

## 실행 방법
`index.html`을 브라우저에서 열면 됩니다.

현재 버전은 서버 없이 동작하는 정적 UI Prototype이며, 데이터는 `app.js`의 mock data로 구성되어 있습니다.

## 주요 화면
- HDPS42 5S 활동 통합 대시보드
- HDPS32 5S Audit 점검항목 기준정보
- HDPS33 팀별 5S Audit 실적
- HDPS34 + HDPS21 연계형 5S 개선요청 등록/조회

## 구성 파일
- `index.html`
- `styles.css`
- `app.js`
- `ARCHITECTURE.md`
