## v2 → v3에서 바로잡은 것

**5S 유형 분류 오류 수정**
이전 버전은 정리·정돈·청소·시각화·**위험구역관리·5S고도화**로 구성했으나, 원본 요청서 1p·2p 표 헤더를 확인한 결과 실제 운영 중인 6개 유형은 **정리·정돈·청소·시각화관리·습관화·자주보전**입니다. "5S 개선표준화"는 유형이 아니라 개별 개선건에 붙는 수평전개 플래그였습니다 — `app.js`의 `REQUESTS[].std`로 재구현했습니다.

**동적 차트 전환 기능 재구현**
요청서 1p에 명시된 기존 MES 기능(차트구분 드롭다운으로 "팀별 유형현황" ↔ "단일 팀 월별 활동추이" 전환)을 HDPS42 대시보드에 그대로 재현했습니다. `차트 구분` / `5S 유형` / `팀 선택` 3개 컨트롤로 동작합니다.

**추가로 반영한 것**
- Audit 등급(S/A/B/C/D) — 참고 PNG의 팀 순위표 방식
- 월별·부서별 Audit 평가 현황 선+막대 결합 추이차트
- 5S 부서별 등록현황 / 5S 상세내역 표 — 요청서 1p 하단 표 재현
- 5S Audit결과 개선현황(개선조치완료율=b/a) 표 — 요청서 7p 표 재현
- HDPS33 조치완료를 정적 뱃지가 아닌 클릭 토글 버튼으로 구현 ("완료처리 버튼 생성" 요청 반영)
- HDPS34 등록 폼을 HDPS21 방식 필드(등록월/공장/대상팀/5S구분/대개선위치/제목/표준화 체크)로 재구성

## v3.1 → v3.2 (반복지적 판정 기준 확정)
반복지적 판정 기준을 **"2개월 이상 연속 지적"**으로 확정 반영했습니다.
- `app.js`의 `computeRepeatStats()`가 팀×유형별 지적 발생 시계열을 만들고, 당월 지적 건 중 **전월에도 같은 팀×유형이 지적되었던 건**만 "반복"으로 집계합니다. 하드코딩된 숫자가 아니라 매번 이 규칙으로 다시 계산됩니다.
- 최초 월(10월)은 비교할 전월 데이터가 없어 반복지적률 산정에서 제외되며, 이에 따라 추이차트·TOP5 모두 **최근 5개월(11월~03월)** 기준으로 표시됩니다.
- TOP5 순위는 팀 Audit 등급 순서(자재운영팀 D등급 → 가공1팀 C등급 → 생산관리팀/Rear조립팀 B등급 → 조립1팀 A등급)와 자연스럽게 일치하도록 팀별 지적 발생확률을 Audit 점수에 연동해뒀습니다.
