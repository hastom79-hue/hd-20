KPI / 산식 기준

인당 개선건수 = 기간 내 개선 완료건수 ÷ 집계인원
인당 표준화건수 = 표준화 완료건수 ÷ 집계인원
반복지적률 = 반복지적건수 ÷ 전체 지적건수 × 100
완료율 = 완료건수 ÷ 개선요청건수 × 100

Workflow / 기한 기준

접수 → 조치중 → 완료
기한 초과 시 ‘지연’ 표시
완료 등록 시 5S 담당자에게 자동 회신
재검증 필요 시 ‘검증대기’ 상태 확장 가능

메일링 / 알림 Rule

개선요청 접수: 생산팀장 즉시 발송
기한 임박: 담당자/팀장 사전알림
기한 초과: 담당자 + 책임자 알림
개선완료: 5S 모듈리더/요청자 회신
월간: 미결·반복지적 요약 발송

권한 / 역할 기준

5S 운영자: 기준정보·Audit·전체조치 조회
생산팀장: 소속팀 개선조치 등록/수정
조치담당자: 배정건 입력
일반사용자: 조회 및 개선요청 등록

기간 / 집계 기준
