# HD-20 Current Baseline — 2026-08-27

이 문서는 2026-08-27 기준 운영본의 최신 요구사항을 고정하는 Baseline이다. 과거 DEVELOPMENT_LOG의 '인정' 중심 표현이나 구형 레이아웃보다 본 문서를 우선한다.

## 1. 화면 안정성
- 새로고침 시 떨림/반복 재렌더링 금지.
- 기능 추가를 이유로 승인 레이아웃을 다시 생성하거나 숨기지 않는다.
- 최종 배치: KPI/운영지표/분석·Raw Data를 먼저 묶고, 고도화 3대 판정기준 + SEQ는 하단 관리체계 영역으로 둔다.
- 3대 기준은 밝은 톤 3카드 가로배치, SEQ는 전체 폭 2색(Blue/Green) 계단형 Gantt.
- 글자 겹침, 과도한 행높이, 불필요한 하단 공백 금지.

## 2. 5S 활동유형
정리 / 정돈 / 청소 / 시각화 / 위험구역관리 / 5S 고도화의 6종으로 통일한다.

5S 활동현황 차트 기본값은 전체 생산팀 × 6개 유형 세로막대 비교이며, 단일 생산팀 선택 시 최근 6개월 유형별 활동추이로 자동 전환한다.

## 3. 고도화 사례 판정
현장 등록과 공식 확정을 분리한다.

흐름: 현장 등록 → 생산혁신팀 + 5S 모듈 판정 → 확정 / 보완요청 / 미확정.

공식 판정주체는 생산혁신팀과 5S 모듈이며, 현장에서 고도화 사례로 등록했다는 이유만으로 고도화 실적에 포함하지 않는다.

### 3대 판정기준
1. 시각화·형적관리
2. 인간공학적 Green Zone
3. 정량축소·정위치 변경을 통한 공간 활용

각 기준 카드는 클릭 시 상세 사진, 설명, 체크포인트, 판정 곤란 사례를 밝은 팝업으로 표시한다.

## 4. GMES 원천데이터 업로드
사내망 GMES 5S 자율개선 추출파일(xlsx/xls/csv)을 별도 가공 없이 업로드한다.

- 원본 컬럼 보존
- 주요 컬럼 자동매핑
- 업로드 직후 판정대기
- 체크박스 다중선택 가능
- 확정 / 보완요청 / 미확정 판정
- 판정자 / 판정일 / 판정사유 저장
- 확정 데이터만 고도화 수준 및 확정이력 반영

## 5. 고도화 수준
고도화 수준은 시스템 임의점수로 자동 판정하지 않는다. 기존 고도화 수준 맵과 공식 판정 결과를 기준으로 관리한다.

'고도화 수준' KPI 클릭 시 기존 수준맵 팝업을 표시한다.

맵/Raw Data/팝업은 동일한 공식 확정 원천데이터를 사용하며, 팀 클릭 시 해당 팀의 확정 사례, 유형, 작업장, 등록일, 판정일, 판정자, 판정사유를 Drill-down한다.

## 6. 운영지표
운영 건전성 KPI는 다음 기준을 사용한다.
1. 공식 판정 완료율
2. 평균 판정 Lead Time
3. 고도화 수준
4. 6개월 유지율
5. Audit 부적합 재발률
6. 기한 내 개선조치 완료율

'인정 합격률' 등 시험/심사 합격 개념을 핵심 KPI로 사용하지 않는다.

## 7. 확정 이후 Lifecycle
확정일을 기준으로 +1M, +3M, +6M 후속점검 일정을 자동 산정한다.

흐름: 확정 → 1개월 점검 → 3개월 Audit → 6개월 Audit → 유지/조치 → 수평전개.

기한경과 또는 Audit 부적합은 문제점·개선조치 Workflow로 자동 연계하며 동일 사례·동일 단계의 중복 개선요청을 생성하지 않는다.

## 8. 문제점·개선조치
BEFORE → 팀/팀장 연계 → 조치내용 → AFTER → 효과확인 → 재발 여부까지 관리한다.

자동 연계 건은 AUTO로 구분한다.

## 9. AI 전문가 가이드
우측 하단의 HDPS · 5S Expert AI는 Prototype 업무지식 가이드이다. 실제 OpenAI API가 연결되지 않은 상태에서 실시간 AI/DB 감시라고 표현하지 않는다.

지원 범위:
- 5S 운영 가이드
- KPI 해석
- 고도화 판정기준
- Audit 재발/부적합 판단
- 개선조치 관리
- 오류 접수
- 오류 이력(LocalStorage Prototype)

## 10. 통합기준정보
최소 다음 정보를 사용자가 확인할 수 있어야 한다.
- 생산팀 표시순서
- 분기별 목표
- 판정주체
- 5S 6개 유형
- 고도화 3대 판정기준
- 1M / 3M / 6M 유지관리 기준

## 11. 다운로드
상단 다운로드는 제거된 구형 차트 DOM이 아니라 현재 화면 데이터를 기준으로 CSV를 생성한다.

포함 대상: 상단 KPI, 운영지표, Portfolio Raw Data, 공식 확정 GMES 사례.

## 12. 변경 금지 원칙
- 사용자 승인 없이 KPI 의미, 3대 기준, 6개 5S 유형, 판정주체를 임의 변경하지 않는다.
- 현장 등록을 공식 확정과 동일하게 취급하지 않는다.
- 구형 '인정' 중심 모듈을 최신 모듈 위에 다시 자동 로드하지 않는다.
- 장시간 setInterval 또는 무제한 DOM 재구성 MutationObserver로 화면을 반복 재생성하지 않는다.
- 새 기능은 기존 화면 정상 여부를 회귀점검한 뒤 반영한다.
