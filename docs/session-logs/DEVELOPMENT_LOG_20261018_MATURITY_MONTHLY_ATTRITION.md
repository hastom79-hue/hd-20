# 개발일지 — 고도화 유지·이탈 월별 검증

- 사용자 화면: 선택팀 고도화 유지·이탈 Drill-down의 일부 월 공백과 이탈 집중.
- web-validation-fixture.js에서 검증 활동의 연중 월 배분을 팀별 결정론적 방식으로 개선.
- 고도화 확정 이후 21~70일 경과한 사례에 한해 기존 팀별 이탈 확률을 높여 빈번한 이탈 검증 가능.
- 미래 시점 이탈/확정은 생성하지 않음. 실데이터는 임의 변경하지 않음.
- 17개 팀 모두 fixture 생성 로직에 포함. 모든 팀·월에서 확정이 보장되는 것은 아니며 실제 확정 데이터 없는 월은 0이 정상.
- JS 구문검사 통과. 브라우저 시각화 및 Actions 검증 미완료.

## 사용자 확정 기준 정정 (최신)
- 고도화 작업장 → 고도화 작업사례로 용어 통일.
- 3대 요건 중 1개 이상 충족 시 고도화 작업사례로 인정; 0개면 이탈.
- 검증 fixture에서 확정 사례의 충족 개수를 1~3개로 배분하고 이탈 사례는 0개로 기록.
- integrated-performance-map.js에서 해당 명칭 교체 및 캐시 갱신.
- JS 구문검사 통과. 실제 브라우저/CI 검증 미완료.
