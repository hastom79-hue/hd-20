# 개발일지 — 팀별 차트 순서 저장

- 사용자 요청: 팀명 드래그 후 변경 순서 저장 기능.
- 명시적 순서 저장 버튼과 기본순서 복원 제공.
- 브라우저 localStorage에 별도 키로 저장하여 새로고침 후 복구.
- 통합기준정보 마스터 순서는 변경하지 않음. 브라우저·기기 간 공유 기능은 아님.
- JS 구문 검사 통과, 실제 브라우저 저장·새로고침 테스트 미완료.

## 기준정보 동기화 요구 반영
- 순서 저장 시 gmes5s_team_display_order에 변경된 순서를 기록하고 이벤트를 발행.
- 필터링된 팀만 드래그한 경우, 미표시 팀의 위치는 최대한 유지.
- 드래그만 한 상태에서는 기준정보 변경 없음. 기본순서 복원은 미저장 변경 취소.
- 동일 브라우저 localStorage 기반 공유이며 다른 브라우저·사용자 서버 동기화는 지원하지 않음.
- JavaScript 구문검사 통과. 실제 화면 동기화 및 기준정보 탭 새로고침 검증 미완료.
