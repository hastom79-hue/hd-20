# HD-20 개발일지 — 팀별 차트 화면 드래그 정렬

- 현장조직 팀별 개선활동 차트에서 팀명 또는 막대를 좌우로 드래그해 화면상 표시 순서를 변경하도록 구현.
- 기본 순서는 통합기준정보 gmes5s_team_display_order 및 팀 마스터를 따름.
- 드래그 변경은 메모리 상태 teamChartLocalOrder에만 반영하며 마스터/localStorage 쓰기 없음.
- 기본순서 복원 버튼으로 기준정보 정렬 복귀.
- 기존 팀 클릭 상세조회 유지.
- 검증: JS 구문 통과. 실제 브라우저 드래그/터치/CSV/모바일 검증 미완료.
