# HD-20 통합기준정보 2차 개선 (2026-10-27)

## 범위
- 메일링 설정: 사용 규칙 필수항목(보고주기, 수신자, 보고대상, 자동메일 조건) 검사, 수신/참조 이메일 형식 검사, 필드별 저장 전 변경내역, 변경 취소, 저장 버튼 활성 조건.
- Audit 운영정책: 기존 정책 유효성 검사는 보존하고 변경항목 미리보기, 변경 취소, 미변경 시 저장 비활성화를 추가.
- 공통: 기존 localStorage 키/이벤트와 기존 데이터 유지, 실제 메일 발송 로직은 호출하지 않음.
- index.html: JS/CSS 캐시 갱신.

## 확인
- integrated-master-factors.js / operating-policy-master.js JavaScript 구문검사 PASS.
- 메일링 규칙 검증/변경 비교/저장 조건, Audit 변경 감지/취소/저장 조건, CSS 및 index.html 연결 정적검사 PASS.
- GitHub Pages에서 실제 사용자 입력과 저장 후 새로고침에 대한 E2E 테스트는 미완료.

## 후속 점검
- 실제 사용 중인 메일링 규칙에서 세미콜론·쉼표 구분 복수 주소 입력 테스트.
- Audit 표본수·유지점검 주기 유효성 검증과 변경 취소 테스트.
- 팀 기준정보 저장 시 입력값 검증과 권한 정책 점검.
