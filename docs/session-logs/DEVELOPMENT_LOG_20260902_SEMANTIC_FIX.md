# HD-20 개발일지 — 효과검증·재발 의미판정 교정

일자: 2026-09-02
대상: `main`

## 문제
문자열 부분일치 정규식으로 상태를 판단하던 일부 코드에서 다음 오판 가능성이 있었다.

- `미발생` 안에 `발생`이 포함되어 있어 재발로 오인 가능.
- `부적합` 안에 `적합`이 포함되어 있어 효과검증 성공으로 오인 가능.

이는 대시보드 재발 건수와 Audit ↔ 개선조치 Case Trace의 현재상태 신뢰도에 직접 영향을 준다.

## 수정

### `dashboard-operational-bridge.js`
재발 판정을 명시값 기반으로 변경.
- 재발: `재발 / 발생 / true / 1 / Y`
- 비재발: `미발생 / 없음 / false / 0 / N`
- 단순 `/재발|발생/` 부분일치 제거.

### `legacy-lifecycle-retirement.js`
승인 대시보드의 재발 건수도 같은 명시값 방식으로 통일.

### `audit-action-case-trace.js`
효과검증 판정:
- 성공: `유효 / 적합 / 검증완료 / 효과확인 / true / 1 / Y`
- 성공 아님: `미흡 / 부적합 / 무효 / 대기 / 미검증 / false / 0 / N`

재발 판정:
- 재발: `재발 / 발생 / true / 1 / Y`
- 비재발: `미발생 / 없음 / false / 0 / N`

Case 편집 Modal을 열 때도 동일 의미판정을 사용하여 `부적합`을 `유효`, `미발생`을 `재발`로 잘못 표시하지 않도록 수정.
