# HD-20 통합기준정보 전면 UI/조작체계 개편 (2026-10-27)

## 사용자 지적
- 기존 통합기준정보 화면은 사이드바 + 나열형 입력창 수준으로 사용성이 낮음.
- 특히 업무·등록항목의 여러 개 textarea는 항목별 편집·삭제·순서 변경과 저장 상태 확인이 불편함.

## 변경사항
1. `integrated-master-factors.js`
   - 줄바꿈 textarea 9개를 분류 목록(좌) + 항목별 행 편집기(우)로 전환.
   - 분류별 항목 개수, 전체 개수, 항목명 검색.
   - 항목 추가·수정·삭제·위/아래 순서 변경.
   - 중복 항목명·빈 항목명 검증.
   - 명시적 저장/변경 취소, 미저장 상태 표시, 변경 취소 시 확인.
   - 분류 이동 시 미저장 변경사항 유지.
   - 기존 localStorage 키 `gmes5s_work_factor_master_v1` 및 `hd20-master-factors-updated` 이벤트 유지.
   - 저장 전까지 데이터 변경 없음. 저장 후에도 기존 등록 사례 변경 없음.
2. `integrated-master-redesign.css`
   - 통합기준정보 헤더/사이드바/기본 테이블 시각 정돈.
   - 새 편집기: 단일 작업영역, 선택된 분류, 순서열, 입력열, 조작열, 하단 저장 바.
   - 반응형 화면 폭 대응.
3. `index.html`: CSS 추가, JS 버전 갱신.
4. `tests/integrated-master-redesign-smoke.cjs` 및 CI workflow 추가.
